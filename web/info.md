# Folder: web

Berisi seluruh halaman HTML **publik** situs (selain `index.html`,
yang sengaja tetap diletakkan di folder utama).

| File | Halaman |
|---|---|
| `category.html` | Jenis & Genre game |
| `donasi.html` | Halaman Donasi |
| `lapor.html` | Halaman Laporkan |
| `post.html` | Halaman detail 1 postingan |
| `search.html` | Halaman hasil pencarian |
| `tentang.html` | Halaman Tentang |
| `404.html` | Halaman "Tidak Ditemukan" — dipakai untuk tautan/halaman yang tidak ada |

Semua halaman di folder ini memakai navbar, sidebar, dan style yang
sama dengan `index.html` (lewat `../css/style.css`, `../js/data.js`,
`../js/main.js`).
