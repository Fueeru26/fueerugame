# Folder: pictures

Folder ini berfungsi sebagai **folder backup gambar-gambar yang akan
diupload di isi (konten) postingan** — misalnya screenshot game atau
gambar tambahan yang disisipkan di dalam teks postingan lewat editor
Admin Panel.

- Folder ini sengaja dikosongkan (tidak berisi gambar bawaan).
- Gambar yang disisipkan ke isi postingan lewat editor Admin disimpan
  sebagai data (base64) di localStorage browser admin; folder ini murni
  tempat menyimpan salinan cadangan (backup) file gambar aslinya.
