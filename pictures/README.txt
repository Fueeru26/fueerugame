Folder ini disediakan untuk gambar-gambar yang diupload dari dalam isi post.

Catatan penting: karena website ini berjalan 100% di sisi browser (tanpa server/backend),
gambar yang diupload lewat editor "Isi Postingan" di Admin Panel akan otomatis disimpan
langsung menempel di dalam isi postingan (format base64), BUKAN disalin sebagai file
terpisah ke folder ini. Jadi folder ini tidak akan terisi otomatis.

Jika nantinya website ini dikembangkan dengan server/backend sungguhan, folder ini bisa
dipakai sebagai lokasi penyimpanan file gambar isi post yang diupload admin.
