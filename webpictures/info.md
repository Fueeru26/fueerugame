# Folder: webpictures

Berisi gambar-gambar tetap (statis) yang dipakai di seluruh tampilan
situs: logo, gambar header navbar, gambar halaman 404, dan gambar
placeholder header postingan.

## Isi folder

| File | Kegunaan |
|---|---|
| `logo.webp` (+ `logo.png` backup) | Logo Fueeru Game (favicon & sidebar) |
| `header.webp` (+ `header.png` backup) | Ilustrasi header di navbar |
| `404.webp` (+ `404.png` backup) | Ilustrasi halaman 404 (Halaman Tidak Ditemukan) |
| `postplaceholder.webp` (+ `postplaceholder.png` backup) | Gambar placeholder header postingan (dipakai karena folder `postheader` dikosongkan) |

## Catatan format gambar

Seluruh gambar sudah dikonversi & dikompres ke format **WebP** agar
situs lebih ringan. **Hanya file `.webp` yang benar-benar dipakai** di
HTML/CSS/JS situs ini. File `.png` dengan nama yang sama tetap
disimpan di folder ini semata-mata sebagai **file cadangan (backup)
kualitas asli** — bukan untuk dipakai langsung oleh situs.
