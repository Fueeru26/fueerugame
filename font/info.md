# Folder: font

Berisi font custom **FredokaOne** (`FredokaOne-Regular.otf` /
`FredokaOne-Regular.ttf`, lisensi lihat `OFL.txt`).

Font ini didaftarkan lewat `@font-face` (nama family: `FueeruDisplay`)
di `css/style.css`, tapi sudah **tidak dipakai** di halaman publik mana
pun — judul bagian "Random Game" & "Recent Update" serta judul postingan
sekarang memakai font Poppins/Inter (lebih formal/profesional). File
font ini disisakan di folder ini saja kalau-kalau ingin dipakai lagi.
