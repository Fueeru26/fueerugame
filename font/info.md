# Folder: font

Berisi font custom **FredokaOne** (`FredokaOne-Regular.otf` /
`FredokaOne-Regular.ttf`, lisensi lihat `OFL.txt`).

Font ini didaftarkan lewat `@font-face` (nama family: `FueeruDisplay`)
di `css/style.css`, dan **hanya** dipakai untuk beberapa teks penting
di halaman publik:

- Judul bagian "Random Game"
- Judul bagian "New Update Game"
- Judul postingan (di kartu Random Game, daftar postingan, dan judul
  halaman detail postingan)

Menu sidebar, isi (konten) postingan, dan seluruh tampilan Admin Panel
sengaja **tidak** memakai font ini — tetap memakai font Poppins/Inter
seperti semula.
