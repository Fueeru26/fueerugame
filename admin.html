Backup & Restore

      


      

        
        
        
        
      


      
Pilih ingin membackup data Postingan atau Halaman (file .json) — jangan lupa selalu backup data secara berkala! Website untuk mengunduh salinan lengkap seluruh file & folder situs (jaga-jaga kalau kehilangan akses ke HP/penyimpanan), dan Deploy untuk mengunggah perubahan situs langsung dari sini tanpa perlu Termux.

      
Kamu akan mendapatkan pemberitahuan pengingat jika tidak melakukan backup selama seminggu.

Backup Website

      


      

        
Backup (Unduh)

        
Unduh salinan lengkap seluruh file & folder situs (kode, gambar, semua yang ada di repo) sebagai satu file .zip. Berguna sebagai cadangan darurat kalau HP atau penyimpanan kamu suatu saat hilang/rusak.

        
Catatan: ini berbeda dari Backup Postingan/Halaman — file ini adalah salinan kode & aset situs, bukan data database.

        
        

      

    


    
    

      

        
        
Deploy Website

      


      

        
Unggah & Deploy

        
Pilih file .zip berisi seluruh isi folder situs kamu untuk langsung mengunggah & men-deploy perubahan — tanpa perlu Termux. File dengan nama sama akan ditimpa, dan file yang tidak ada di dalam zip akan dihapus dari situs live (zip dianggap sebagai kondisi lengkap terbaru).


        

        
        

        

          

          

        

      


      

        
Struktur zip

        
zip wajib berisi file index.html — sistem otomatis mendeteksi folder tempat index.html berada sebagai root situs (jadi boleh dibungkus 1 folder tambahan atau tidak, sama-sama valid). Kalau index.html tidak ditemukan, unggahan akan ditolak — sekaligus jadi pengaman kalau salah pilih file zip.

      


      

        
Cara Kerja Unggah

        
Karena ada batasan jumlah permintaan per proses, file diunggah bertahap (dicicil) dalam beberapa batch berisi maksimal 35 file, satu per satu sampai semua selesai — makanya progress bar akan naik bertahap, bukan langsung 100%. Setelah semua batch terunggah, sistem otomatis merakitnya jadi 1 kali pengiriman (commit) ke GitHub, yang lalu memicu GitHub Actions untuk men-deploy ke Cloudflare secara otomatis (±1-2 menit).
